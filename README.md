# Crazy Bubble 🫧

**Crazy Bubble** — это анимированная игра-песочница с разноцветными шариками.

Шарики двигаются по экрану, сталкиваются друг с другом и смешивают свои цвета.
Игрок может «всасывать» шарики мышкой в инвентарь, «выплёвывать» их обратно,
а также удалять шарики в специальной зоне.

## Управление 🎮

| Действие | Описание |
|---|---|
| **ЛКМ по шарику** | Всосать шарик в инвентарь (он исчезает с поля и следует за курсором) |
| **ЛКМ по пустому месту** (с шариком в инвентаре) | Выплюнуть шарик обратно в направлении курсора |
| **ЛКМ по зоне DELETE** (с шариком в инвентаре) | Удалить шарик |
| **Закрыть окно** | Выйти из игры |

## Как это работает

1. При запуске создаётся указанное количество шариков случайных цветов.
2. Шарики движутся и отскакивают от стенок окна.
3. При касании двух шариков их цвета математически усредняются по RGB.
   Чем больше шариков смешивается, тем разнообразнее становятся цвета.
   Если смешать много разных цветов, можно получить серый или белый цвет —
   это считается плохим результатом.
4. Игрок может забрать шарик с поля мышкой, а затем выпустить его обратно
   или удалить.

## Локальный запуск

### Требования

- **Python 3.8+**
- **Pygame** (библиотека для графики)

### Установка и запуск

```bash
# Установить зависимости
pip install pygame

# Запустить игру
python gui.py
```

### Настройка

В начале файла `gui.py` можно изменить параметры:

| Параметр | По умолчанию | Описание |
|---|---|---|
| `SCREEN_WIDTH` | 800 | Ширина окна (пиксели) |
| `SCREEN_HEIGHT` | 600 | Высота окна (пиксели) |
| `BALL_RADIUS` | 20 | Радиус шарика (пиксели) |
| `NUM_BALLS` | 15 | Стартовое количество шариков |
| `FPS` | 60 | Кадров в секунду |
| `MOVE_SPEED` | 7 | Скорость выплёвывания шарика |

## Запуск в Docker-контейнере 🐳

Для запуска с графическим окном требуется X-сервер (на Windows —
[VcXsrv](https://sourceforge.net/projects/vcxsrv/) или [WSLg](https://github.com/microsoft/wslg);
на Linux — встроенный X11; на macOS — [XQuartz](https://www.xquartz.org/)).

### Сборка образа

```bash
docker build -t crazy-bubble .
```

### Запуск (Linux — X11 сразу)

```bash
docker run --rm -e DISPLAY=$DISPLAY -v /tmp/.X11-unix:/tmp/.X11-unix crazy-bubble
```

### Запуск (Windows с VcXsrv)

1. Запустите **XLaunch**.
   - Выберите "Multiple windows".
   - Display number оставьте `0`.
   - Отметьте "Disable access control".
   - Нажмите "Завершить".
2. Узнайте IP-адрес хоста (команда `ipconfig`, обычно что-то вроде `192.168.x.x`).
3. Запустите контейнер:

```bash
docker run --rm -e DISPLAY=192.168.x.x:0 crazy-bubble
```

### Запуск (macOS с XQuartz)

```bash
xhost + 127.0.0.1
docker run --rm -e DISPLAY=host.docker.internal:0 -v /tmp/.X11-unix:/tmp/.X11-unix crazy-bubble
```

## Цветовая модель

Шарики используют цветовую модель RGB (Red, Green, Blue).
При столкновении цвет каждого шарика вычисляется как среднее арифметическое
двух RGB-компонент:

```
новый_R = (R1 + R2) // 2
новый_G = (G1 + G2) // 2
новый_B = (B1 + B2) // 2
```

Это универсальный подход — любые два цвета могут смешаться,
давая точный предсказуемый результат без ручной настройки.
